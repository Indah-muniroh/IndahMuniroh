Tentang Saya

Saya adalah siswa jurusan Rekayasa Perangkat Lunak (RPL) di SMKN 8 Jember. Perjalanan saya di dunia pemrograman berawal dari rasa penasaran tentang bagaimana sebuah halaman web bekerja di balik layar. Sejak saat itu, saya mendedikasikan waktu untuk terus belajar, mengeksplorasi teknologi web modern, serta mengikuti kelas industri seperti Hummatech dan Smartcoding untuk mengasah kemampuan saya.

Bagi saya, tantangan logika dalam koding bukan sekadar tugas, melainkan sebuah teka-teki seru untuk dipecahkan. Saya selalu antusias menyambut proyek baru, senang berkolaborasi, dan berkomitmen untuk terus berkembang menjadi pengembang perangkat lunak yang handal.
